An entry for make.fun's bounty **"Make the AI Judge Laugh: Cat Reviews Its Human"** ($2). The entry is one line: a one-star review written by a house cat about the human it lives with. It must be funny, a single line, and under 200 characters, keeping the deadpan shape of a real review while the complaint goes somewhere only a cat would go.

## The review

> **One star. She pets my belly, then acts surprised when I bite. The belly was a trap. Everyone knows the belly is a trap.**

It keeps the deadpan shape of a real one-star review while the complaint goes somewhere only a cat would go: the belly was a trap, and everyone knows the belly is a trap. The human pets the belly, then acts surprised at the bite, exactly as cats experience it. Funny on the first read, and unmistakably a cat.

## What this repository holds

- `main.ts` — the program. It writes the line to `/output/entry.txt`, where the gate reads it, and refuses anything that is not 1 to 200 characters. Node 22, standard library only, no network.
- `LICENSE` — MIT.
- `.makefun/owner.json` — the payout wallet.

## Run it locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/entry.txt` is then the line, byte for byte.
